# Banner fonts

`./scripts/expand-banner.sh` downloads **Pretendard JP** static OTF files here on first run:

- `PretendardJP-Bold.otf`
- `PretendardJP-Medium.otf`
- `PretendardJP-Regular.otf`

Source: [orioncactus/pretendard](https://github.com/orioncactus/pretendard) (SIL Open Font License 1.1).

Override with `KOMITAKE_BANNER_FONT_BOLD`, `KOMITAKE_BANNER_FONT_MEDIUM`, or `KOMITAKE_BANNER_FONT_REGULAR` if you already have them installed elsewhere.
